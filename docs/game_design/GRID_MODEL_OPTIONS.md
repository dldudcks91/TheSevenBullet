# 격자 모델 선택지 — 3×3 영웅 vs 4×4 포커

> **상태: 결정됨 — 3×3 종족×직업.** 확정 내용은 [GAME_DESIGN.md](GAME_DESIGN.md)에만 적는다.
> 이 문서는 나중에 같은 논의를 반복하지 않기 위한 **판단 근거 기록**이다. 아래 본문은 결정 당시의 검토를 그대로 남긴 것이며, 결론과 어긋나는 서술이 있어도 고치지 않는다.

## 결론과 이유

포커안을 접고 **3×3 격자 + 종족×직업**으로 간다. 결정적이었던 것은 넷이다.

1. **포커는 축이 둘뿐이라 표현 예산이 없다.** 무늬는 진영, 랭크는 강약으로 이미 차 있어서, 몬스터 카운터에 필요한 축(데미지 타입·타격 패턴)을 실을 자리가 없다. 종족×직업은 직업 이름이 곧 카운터 정보라 이걸 공짜로 한다.
2. **"물량이 싸다"는 포커 고유의 이점이 아니었다.** 조합형 설계의 이점이고, 종족 규칙 + 직업 규칙으로도 똑같이 얻는다. 아래 「두 방향의 트레이드오프」의 콘텐츠 물량 항목은 이 점에서 틀렸다.
3. **3×3의 차별화 주장도 틀렸다.** 반격 없는 적과 이월되는 방어선은 타워디펜스의 장르 표준이라 차별화 근거가 못 된다. 차별화는 격자 모델이 아니라 성벽 이월·매 라운드 보스전·전진과 맞물린 상태이상이 담당한다.
4. **한 칸에 부대를 세우기로 하면서 칸 크기가 제약이 됐다.** 4×4는 같은 화면에서 칸 면적이 절반이라 무리가 들어가지 않는다.

포커에서 가져올 만했던 것 — **숫자가 클수록 강한데 조합은 약한 카드를 요구한다**는 긴장 — 은 인원과 체급이 유닛마다 정해지는 방식으로 대체했다. 강한 유닛일수록 머릿수가 적어 완충재가 얇다.

## 무엇이 갈리는가

배치 격자의 크기와 평가 규칙을 어떻게 잡느냐인데, 실제로는 **더 근본적인 것**이 갈린다.

> **영웅의 정체성이 개체에 있느냐, 속성에 있느냐**

- **3×3 영웅** — 영웅은 고유한 개체다. 아이템을 끼고, 패시브가 있고, 역할이 있다
- **4×4 포커** — 영웅은 속성 조합이다. 카드가 곧 영웅이며, 개성은 얇아야 한다

발라트로 카드에 능력이 없는 것은 우연이 아니다. **카드가 개성을 가지면 조합 규칙이 마비된다** — 매번 "이 스킬을 버리고 무늬를 맞출까"를 저울질하게 되기 때문이다. 반대로 영웅이 강한 고유 패시브를 가지면 무늬·숫자는 장식이 된다.

따라서 두 모델은 공존이 어렵다. 한쪽이 크면 다른 쪽이 노이즈가 된다.

## 4×4 포커안의 구조

핸드는 **4장**으로 평가한다. 5장 포커는 격자 한 줄에 안 들어가고, 4장이면 포카드·플러시·스트레이트·트리플·투페어·원페어·하이카드가 성립해 충분하다.

**랭크 = 직업**

| 랭크 | 역할 |
|---|---|
| J | 전사 |
| Q | 성직자·버퍼 |
| K | 리더 — 전군에 영향 |
| A | 와일드·특수 |
| 숫자 | 병사 계열 — 숫자가 클수록 강함 |

**무늬 = 변형**

| 무늬 | 변형 |
|---|---|
| ♠ | 공격형 |
| ♥ | 방어·지속형 |
| ♦ | 속도형 |
| ♣ | 유틸형 |

원형(랭크)과 변형(무늬)의 곱으로 전체 종류가 나오므로, **만드는 것은 원형 수 + 변형 규칙**이면 된다. 신규 영웅을 종류만큼 만드는 것보다 훨씬 싸다.

### 포커 핸드가 파티 편성 철학으로 번역된다

- **포카드** — 한 직업 특화
- **플러시** — 한 방향 몰빵
- **스트레이트** — 균형 편성
- **투페어** — 두 직업 이원화

핸드 이름이 곧 빌드 이름이 된다. 억지로 붙인 것이 아니라 구조가 같아서 맞아떨어진다.

### 숫자 카드에서 나오는 트레이드오프

숫자가 클수록 강하면, **스트레이트를 맞추려면 약한 카드를 써야 한다.** 핸드 보너스와 개별 성능이 자동으로 충돌한다. 별도 장치 없이 얻는 긴장이다.

---

## 두 방향의 트레이드오프

| | 3×3 영웅 | 4×4 포커 |
|---|---|---|
| 차별화 | **있음** — 반격 없는 몬스터 + 성벽 + 배치, 이 조합의 게임은 없다 | **흐려짐** — 발라트로 그림자 |
| 콘텐츠 물량 | **많이 필요** — 영웅·아이템·시너지를 계속 만들어야 한다 | **적게 필요** — 랭크×무늬로 조합이 폭발한다 |
| 현재 설계 | 거의 그대로 살아남는다 | 상당 부분 다시 짠다 |

물량은 실제 제약이다. 발라트로를 소수 인원이 만들 수 있었던 이유가 카드라는 **이미 존재하는 문법**을 빌렸기 때문이다.

---

## 발라트로 아류 리스크

포커 + 전술카드 + 상점을 모두 넣으면 표면 유사도가 최대가 된다. 다만 핵심 동사는 다르다 — 발라트로는 손패에서 **내는** 게임이고, 이 게임은 격자에 **놓는** 게임이다. 발라트로에는 배치·인접·칸 가치가 아예 없다.

**진짜 문제는 "클론인가"가 아니라 "클론으로 읽히는가"다.** 스토어 페이지 스크린샷에는 배치가 보이지 않는다.

### 관리 방법 — 전술카드를 핸드가 아니라 격자에 건다

전술카드가 포커 핸드만 참조하면 조커를 그대로 베낀 것이 된다. 격자를 참조하면 **발라트로가 만들 수 없는 카드**가 된다.

❌ 핸드 참조 — "플러시면 배수", "페어당 가산"
✅ 격자 참조 — "가운데 영역의 영웅 강화", "같은 열에 같은 직업이 둘이면 그 열 강화", "모서리가 비어 있으면 나머지 전원 강화", "가장 앞 열은 몬스터가 도달하기 전까지 강화"

포커 핸드를 전술카드가 참조할 수 있는 **여러 대상 중 하나**로 격하시키면 무게중심이 포커에서 격자로 옮겨간다.

### 판별 테스트

한 문장으로 설명했을 때 포커가 어디에 오는지를 본다.

- ❌ *"포커 핸드를 맞춰 점수를 내는 로그라이크"* → 아류
- ✅ *"격자에 영웅을 배치해 성벽을 지키는 로그라이크 타워디펜스. 배치한 줄이 포커 핸드를 이루면 강해진다"* → 다른 게임

포커가 **두 번째 절**에 머무르면 괜찮고, 첫 절로 올라오면 아류다.

### 그 외 완화

- 명칭을 "조커"가 아니라 **전술카드**로 유지
- 카드 모양 대신 영웅 형상에 랭크·무늬 표식만 작게 — 첫인상이 영웅 게임이 된다
- 5장이 아닌 **4장 핸드**라 규칙 자체가 미묘하게 다르다

---

## 포커로 갈 경우 살아남는 것 / 다시 짜는 것

**살아남음** — 성벽 + 전진하는 몬스터, 반격 없는 전투, 상태이상, 아이템 액티브, 상점 드래프트

**다시 짬** — 격자 크기, 인접 버프(빠질 가능성 높음), 영웅 정의 방식 전체

전투 모델은 그대로고 **배치 규칙만 갈아끼우는** 구조라, 보이는 것보다 파괴적이지 않다.

---

## 남은 우려

- **인접 버프와 핸드가 동시에 있으면 마비 위험.** 규칙 두 개를 동시에 만족시켜야 하면 깊이가 아니라 마비가 될 수 있다. 아마 하나를 골라야 한다 — 핸드로 가면 인접은 빼는 쪽이 깔끔하다
- **드래프트 제약이 세진다.** 벤치가 없는데 무늬까지 맞춰야 하면 원하는 조합이 안 나올 확률이 급증한다. 무늬 변경 수단이나 와일드가 사실상 필수가 된다
