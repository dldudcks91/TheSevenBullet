# Balatro — 조커 수집 자료

외부 게임 참고자료. **이 프로젝트의 기획 확정 내용이 아니다.**

## 파일

| 파일 | 내용 |
|---|---|
| `balatro_jokers.csv` | 조커 150종 전체 — 이름·등급·가격·효과 원문 + `mechanism` 분류 |

`mechanism` 컬럼은 원본 게임에 없는 **이쪽에서 붙인 분류**다. 전술카드 종류를 나누기 위한 작업용 태그이며, 효과가 무엇을 참조하고 언제 발동하는지로 갈랐다.

## 참고 시 주의

발라트로는 **핸드를 낸다 → 점수가 계산된다**는 이산적 박자가 있어서, 조커 상당수가 "낸 패에 X가 있으면"이라는 조건절을 쓴다. TheSevenBullet에는 그 박자가 없다(실시간·연속). 조건절 형태는 그대로 못 가져오고, **무엇을 참조하는가**의 목록으로만 쓴다.
