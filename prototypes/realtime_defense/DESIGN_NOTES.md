# PROTOTYPE — realtime_defense

> **PROTOTYPE - NOT FOR PRODUCTION.** 버리는 코드다. `src/`에서 이 폴더를 import하지 않는다.
> Date: 2026-08-11 (개조) · 최초 2026-08-05 · 기준: [GAME_DESIGN.md](../../docs/game_design/GAME_DESIGN.md)
>
> 앞선 두 프로토는 현재 설계와 어긋난다. `grid_wall_defense`는 턴제 배치 검증(칸당 1명),
> `poker_grid`는 기각된 모델이다. 이 프로토가 현재 설계의 프로토다.

## 핵심 질문

> **흐르는 시간 속에서 구매·배치 판단이 실제로 성립하는가?**

라운드도 정비 단계도 없다는 것이 이 설계의 근본 전제다. 여기서 "정신없어서 아무 판단도 못 한다"가
나오면 상점·전투·겹침 설계 전부가 무의미하다. 부수 측정 두 가지를 같이 태웠다 — 킬 속도가 실제로
여유 시간으로 환산되는가(B), **감산·비율 두 공식이 "보스마다 답이 갈린다"를 실제로 만드는가**(C).

## 실행

Godot 4로 `TheSevenBullet` 폴더를 연다. `project.godot`의 `run/main_scene`은 이 프로토를 가리키게
바꿔 두었다. F5.

**화면:** 왼쪽부터 **3×3 격자 → 성벽 → 보스 레인**(오른쪽 끝에서 걸어온다). 오른쪽 위 구석에
**예고 슬롯**. 하단은 **5슬롯 매대 · 리롤 · 성벽 패널 · 측정 패널**, 그 아래 **유물 슬롯 줄**.

| 조작 | |
|---|---|
| 병사카드 → 칸으로 드래그 | 구매 (결제는 드롭 순간) |
| 유물카드 → 유물 슬롯 줄로 드래그 | 구매. 유물은 칸에 붙지 않는다 |
| 배치된 부대끼리 드래그 | 자리 교체 (즉시·무료) |
| 부대·보스·매대 카드·유물·예고 슬롯에 **호버** | 오른쪽 아래에 **상세 카드**가 뜬다 |
| 같은 것을 **클릭** | 상세 카드 고정(핀). `[Esc]`로 해제 |
| `[Space]` | 일시정지 — **정지 중 모든 입력 차단** (설계 규칙 그대로) |
| `[S]` | 스폰 모드 전환 (고정 스케줄 ↔ 킬 연동) |
| `[Z][X][C]` | 1x / 2x / 4x · `[R]` 재시작 |

> **발동 버튼이 없다.** 예전 프로토의 `[1]`~`[9]` 아이템 발동은 기획이 바뀌며 사라졌다 —
> 유물은 전역 보유이고, 효과는 그 직업 부대들의 박자에 실려 **자동으로** 나간다.

## 만든 것

- **무정지 실시간.** 라운드 없음. 보스가 스케줄대로 계속 오고, 그 위에서 전부를 판단한다
- **한 칸 = 한 부대.** 티어가 인원과 개체 크기를 정한다(6/4/3/2/1명, 스프라이트 스케일 연동)
- **물리는 뺀다.** 칸 공격력을 인원이 나눠 **타격당 딜**을 만들고, 거기서 보스 방어력을 뺀다.
  **최소 보장은 없다 — 못 넘기면 0이다.** 잘게 쪼갤수록 손해라는 트레이드오프가 여기서 나온다
- **마법은 곱한다.** 원소 저항값을 그대로 감소율로 쓰고(디아블로식), 상한 `RES_CAP`(임시 75%)을
  둔다. **인원과 무관하다** — 마법 부대는 인원이 몇이든 캐스팅 딜이 같다
- **원소 4종**(냉기·화염·독·번개). 저항 하나가 두 일을 한다 — 그 원소 피해의 감소율이면서
  그 원소 상태이상의 저항이다
- **캐릭터 위에는 이름만 둔다.** 격자 칸에는 부대 이름, 보스 위에는 이름과 **접두사**
  (`질주 · 냉기 저항`, `거물 · 중장갑 · 재생`) — 디아블로의 유니크 표기 방식이다. **가진 것만
  적는다.** 스펙(체급·타격당 딜·방어력·저항 수치·걸린 상태이상)은 전부 상세 카드로 갔다
- **상세 카드.** 호버하면 오른쪽 아래(측정 패널 자리)에 카드가 뜨고, 클릭하면 고정된다.
  부대·보스·매대 카드·보유 유물·예고 슬롯이 전부 같은 카드 문법을 쓴다. 카드 안에서
  `16.5 - 방 3 = 13.5` 처럼 **감산 과정이 그대로** 보이고, 마법은 `번개 저항 48% → 98`.
  딜 0인 칸은 그 줄이 붉게 뜬다
- **통함 / 딜 0 사전 표시는 매대 병사카드에 남는다.** 구매 판단은 흐르는 시간 속에서
  즉시 이뤄져야 해서, 매물만은 호버 없이도 읽히게 뒀다
- **직업 리듬 3종** — 궁수(평타마다 확률 발동) / 마법사(캐스팅, 평타 없음, 보스에게) /
  사제(캐스팅, 평타 없음, 아군에게 축복). 전사는 **스킬 없이 평타만** — 감산 공식의 기준선이다
- **크리티컬은 궁수만.** 기본 0%이고, 궁수 스킬로만 생긴다. 인원이 많으면 한 박자에 여러 번 굴려
  거의 확정으로, 적으면 드물게 터진다
- **유물 = 동사.** 전역 보유(4슬롯), **[직업] 태그가 수행 주체를 정하고**, 쿨다운은 초가 아니라
  **그 부대의 박자 수**로 찬다. 같은 밀어내기도 다수·빠른 부대에선 잦고 작게, 소수정예에선 드물고
  크게 나간다. 7종 — 넉백[전사] · 파쇄[전사] · 화상[궁수] · 중독[궁수] · 빙결[마법사] ·
  스턴[마법사] · 취약[사제]
- **상태이상 7종**을 위 유물이 공급한다. 원소가 붙은 것은 해당 저항이 지속·세기를 깎는다
- **보스 아키타입 5종** — 돌격형·장갑형·주술형·재생형·거물. **주술형은 개체마다 막는 원소가 다르다**
  (스폰 시 굴린다) — 내 빌드를 정통으로 막을 수도, 허공에 뜰 수도 있다
- **예고 슬롯** — 다음 보스의 정체·접두사·남은 시간. 호버하면 상세 카드로 체력·방어력·원소
  저항 프로필까지 편다. 예고에서 본 단어가 전투에서 그대로 다시 보인다
- **최근접 타게팅** + **겹침**(앞 보스가 살아 있어도 다음이 온다) + **밀어내기 저항의 시간 상승**
- **5슬롯 매대** — 첫 매대는 병사카드로만, 킬하면 무료 갱신 + 리롤가 원가 복귀, 구매한 슬롯은
  다음 갱신까지 빈 채, 리롤은 연속마다 비싸짐
- **성벽** — 런 전체를 관통하는 단일 지속 자원. 매대 밖 고정 패널에서 수리(현재)/최대HP 업그레이드(미래)
- **칸별 기여도** — 누적 딜과 비율 막대

## 의도적으로 뺀 것

기획에서 **아직 정해지지 않은 것들**이라 넣지 않았다. 지어내서 채우면 프로토가 기획을 앞질러버린다.

- **기사 · 암살자 · 리더** — 발동 방식이 「미결」이다. 전사도 스킬 없이 평타만 친다
- **사기** — 증감 규칙과 구간 보너스가 정해지지 않았다
- **저주** — 갈래 목록과 덮어쓰기 규칙이 미결이다. 나머지 7종만 넣었다
- **유물 상한이 찼을 때의 교체·처분** — 규칙이 미결이라 4칸이 차면 더 못 산다

그 밖에 프로토 범위 밖이라 뺀 것: 전술카드 · 종족 시너지 · 보스의 병력 디버프 · 구간/거물 연출 ·
언락 · 밸런싱.

> 디버프를 뺐으므로 **"인원이 디버프 완충재"** 축은 이 프로토가 검증하지 않는다. 인원이 하는 일
> 셋 중 둘(타격 쪼개기, 고정값 증폭)만 걸려 있다. 같은 이유로 **아군에게 걸리는 스턴**(캐스팅이
> 통째로 날아가는 것)도 태우지 못한다 — 보스가 병력에게 아무것도 못 하기 때문이다.

## 취한 단축

- 수치 전부 하드코딩. `src/data/`로 옮기지 않는다
- **공격 주기의 출처는 직업으로 고정했다** — 기획상 「미결」인 항목이다(유닛마다 다를 수도 있다)
- 에러 처리 없음. 스프라이트 로딩은 `grid_wall_defense`의 것을 다시 줄여 베낌(import 금지, 복사만)
- 재배치를 **즉시·무료**로 뒀다 — 「미결」의 한쪽 극단이다. 제약을 두는 쪽은 안 만져봤다
- 골드는 킬 보상만. 겹쳐서 잡은 보스도 동일 지급
- 사제 축복은 **사제별로 따로** 들고 있다가 합산한다. 같은 사제의 재캐스팅은 자기 몫을 덮어쓰고,
  사제가 둘이면 겹친 만큼 적용된다(기획의 "효과는 전부 중첩된다" 그대로)

## 스폰 모드 두 가지 — 「미결」 1순위를 직접 태운 것

「미결」의 *"강하면 다음 스폰까지 멍하니 기다리고, 킬 즉시 스폰이면 숨 돌릴 틈이 없다"* 를 앉아서
고르지 않고 `[S]`로 갈아 끼우며 비교하게 했다.

| 모드 | 규칙 |
|---|---|
| **고정 스케줄** | 스폰 시각이 절대적. 빨리 잡으면 그만큼 온전히 논다 |
| **킬 연동** | 킬하면 3.5초 뒤 다음 한 마리를 당겨온다. 스케줄은 상한으로만 남아 안 죽여도 결국 온다 |

## 헤드리스 검증

`_smoke.gd`는 무입력 실행으로는 안 타는 경로(드래그 구매·유물 구매·자리 교체·패널 구매·무효
드롭)를 강제로 태우는 임시 봇이다. 고정 편성으로 끝까지 돌린다.

```
godot --path . --headless --fixed-fps 60 --script prototypes/realtime_defense/_smoke.gd
godot --path . --headless --fixed-fps 60 --script prototypes/realtime_defense/_smoke.gd -- adaptive
godot --path . --fixed-fps 60 --script prototypes/realtime_defense/_smoke.gd -- shots=<폴더>   # 스크린샷
```

**봇 실행 결과 (사람 손이 아니라 고정 9칸 편성 + 유물 4개, 중간 교체 없음 — 밸런스 판정이 아니라
기전 확인용).** 유물 네 칸 중 전사 몫만 바꿔가며 두 번 돌렸다.

| | 넉백[전사] · 화상 · 빙결 · 취약 | **파쇄**[전사] · 화상 · 빙결 · 취약 |
|---|---|---|
| 고정 스케줄 | 패배 (8/12, 137.2s) | **클리어** (12/12, 168.3s, 성벽 512 남음) |
| 킬 연동 | 패배 (11/12, 176.8s) | **클리어** (12/12, 127.9s, 성벽 590 = 무피해) |
| 평균 처치 소요 | 9.7s | 7.4s / 7.0s |
| 최대 겹침 | 3마리 / 2마리 | 2마리 / 1마리 |
| 딜 0 타격 비율 | 76% | **31% / 30%** |
| 물리 감산 손실 | 73% / 75% | **37% / 34%** |

**여기서 실제로 확인된 것 — 파쇄 유물 하나가 판을 통째로 뒤집는다.** 같은 편성·같은 보스인데
전사 유물을 넉백에서 파쇄로 바꾸는 것만으로 패배가 무피해 클리어가 됐다. 저티어 검사대의 누적
기여가 161 → 1302, 궁수대가 603 → 3437로 뛴다. 감산 세계에서 **방깎은 딜 버프가 아니라 딜 0을
0이 아니게 만드는 스위치**라, 값이 선형으로 붙지 않고 계단으로 붙는다는 뜻이다.

이것이 기획의 「미결」 *"물리 면역이 발생한 판을 매대가 어떻게 구제하는가"* 에 대한 첫 데이터다.
답은 있다 — 다만 **너무 잘 들어서, 파쇄를 뽑았는가가 그 런의 승패가 되어버릴 위험**이 같이 보인다.
가중치·리롤·갱신 속도 중 무엇으로 풀지는 여전히 열려 있고, 이 프로토는 "풀 수는 있다"까지만 말한다.

한편 스폰 모드는 두 번 다 같은 방향을 가리킨다 — **킬이 느려지면 스케줄이 그냥 다음 놈을 얹어서
눈덩이가 된다.** 즉 "제한시간 대신 감당할 것이 하나 는다"가 기전 수준에서는 작동한다. 문턱 시절과
결론이 같다. 다만 잘 굴러가는 판(파쇄 쪽)에서는 킬 연동이 오히려 **더 빨리 끝나고 겹치지도 않았다**
(1마리 유지) — 킬 속도가 여유를 사는 대신 다음 놈을 당겨오므로, 강한 편성일수록 런이 짧아진다.

## 확인해볼 것

| | 무엇을 보는가 |
|---|---|
| 첫 보스 두세 마리 | 전투를 보면서 카드를 읽고 살 수 있는가, 아니면 화면 하나를 포기하게 되는가 |
| 킬 직후 | 매대 갱신을 **알아채는가**. 갱신이 보상으로 느껴지는가 |
| 겹쳤을 때 | 두 마리가 되면 회복하려 드는가, 그냥 포기하게 되는가 |
| **이름만 남긴 격자** | 칸 위가 비어서 편한가, 아니면 매번 호버해야 해서 답답한가 |
| **상세 카드** | 흐르는 시간 속에서 카드를 읽을 틈이 나는가. 고정(핀)을 쓰게 되는가 |
| **보스 접두사** | `질주 · 냉기 저항` 몇 단어로 대응이 정해지는가, 아니면 결국 수치를 보러 가는가 |
| 매대의 통함 / 딜 0 | 감산 결과를 보고 구매를 실제로 바꾸는가, 아니면 그냥 비싼 걸 사는가 |
| **파쇄를 뽑았을 때 / 못 뽑았을 때** | 봇에서 승패가 갈렸다. 사람 손에서도 그런가, 아니면 다른 답을 찾는가 |
| 마법 `화 48%` 표시 | 원소를 갈아타게 되는가. 몰빵과 섞기 중 어느 쪽으로 기우는가 |
| 주술형 보스 | 막는 원소가 매번 달라지는 것이 "예고를 보게" 만드는가, 그냥 운으로 느껴지는가 |
| 유물 자동 발동 | 발동이 **보이는가**. 자동이라 존재를 잊게 되지는 않는가 |
| 유물 [직업] 태그 | 유물이 편성을 끌고 가는가 (그 직업을 더 사게 되는가) |
| 예고 슬롯 | 다음 보스를 보고 쇼핑하는가, 아니면 지금 보스만 보는가 |
| 성벽 패널 | 카드와 수리 사이에서 갈등이 생기는가 |
| `[S]` 두 모드 | 어느 쪽이 "킬 속도가 여유를 산다"로 느껴지는가 |

**핵심 체크:** 위의 어느 하나라도 "볼 틈이 없다"로 답이 나오면 실시간 전제가 흔들린다. 그때
고칠 곳은 UI가 아니라 **스폰 스케줄**이다.
