## 1. 재미 관점 헛점 리뷰 (Claude 분석)

### 주요 8건

1. **에이전시 곡선 역전** — 가장 긴장된 순간(성벽 타격 중·초읽기)에 골드가 없으면 할 수 있는 게 없다. 긴장 최고점 = 에이전시 최저점.
   - 제안 방향: "전투 입력 없음" 철학 안에서 경제 행동을 위기 수단으로 — 초읽기 중 리롤 할증 동결, 또는 성벽 패널에 유료 긴급 수단.
2. **안티-캐치업 스택** — 딜 0 판에서: 킬 없음 → 리롤 초기화 없음 → 답 뽑기 비싸짐 → 성벽 내주며 버팀 → 수리비는 런 갈수록 상승. 겹침 킬 캐치업은 "겹친 뒤"에만 작동하고, 그 앞 단계(한 놈에게 막힘)에는 캐치업이 없다.
   - 제안 방향: 리롤 할증에 시간 감쇠 / 딜 0 감지 시 풀 가중치 연동.
3. **'답'이 풀에서 희소** — 중장갑의 답(마법/소수정예) 중 마법 딜러가 30유닛 중 5. 물리 편향은 명중 도입 근거였지만 동시에 매대의 답 공급률을 낮춘다.
   - 제안 방향: 밸런스 가드레일로 "딜 0 상태에서 유효한 카드가 풀의 몇 %인가"를 접두사별로 계산·관리.
4. **후반 포화 = 유일한 활동(쇼핑)의 죽음** — 9칸·인원·유물·전술 상한이 다 차면 매대가 소음이 되고, 그 시점이 4막(클라이맥스)과 겹칠 위험. 미결 「성장 축이 9칸 밖에 필요한지」가 재미 관점 최우선.
   - 목표선 제안: "포화 이후에도 매 매대에 최소 한 장은 의미가 있어야 한다."
5. **통함/막힘 표시가 '현재 보스' 기준** — 예고 슬롯의 존재 이유는 "다음 놈 대비 쇼핑"인데 배지는 현재 보스를 가리킨다 (신규 발견, 미결에 없음).
   - 제안: 예고 슬롯 호버 시 매대·배치 부대의 통함/막힘이 그 적 기준으로 전환 (호버=읽기 문법 재사용, 수정 쌈).
6. **사기 = 사실상 숨은 패시브** — 구간 보너스가 조용히 붙으면 "무엇 때문에 세졌는지 추적할 수 없다"(패시브 거부 근거)와 자기 충돌.
   - 제안 방향: 증감 규칙을 정할 때 플레이어가 조작 가능한 축으로 (악마는 태우고 인간은 올리는, 종족 정체성 연결). 구간 전환은 화면에서 사건으로 보여야.
7. **원소 조기 커밋 vs 4막 셔플** — 몰빵은 1막에 커밋되는데 처벌 횟수는 후반 셔플이 정한다. 선택 시점 정보 0이면 낙차가 판단이 아니라 주사위로 읽힘. 원소 강화 셔플이 막보스에도 적용되는지 문서에 불명확.
   - 제안: 최소한 4막 막보스의 원소 구성은 런 초반부터 조회 가능하게 (막보스 상시 표시 원칙의 확장).
8. **전투 안무 단조** — 모든 교전이 "한 놈이 걸어온다". 접두사가 수학은 다양하게 만들지만 화면 사건은 런 내내 동일. 전투가 자동이라 발라트로보다 장면 부담이 큼.
   - 제안: 접두사 확장 시 스탯 축보다 움직임 축(전진 속도·밀어내기 저항·광폭 계열) 우선.

### 기타 짧은 것들

- **명중 미결** — 재미 관점에서 "약화된 타격" 쪽 지지. 대형·리더의 연속 빗나감은 눈에 보이는 억울함, "왜 이겼는지 안다" 원칙과 최대 충돌 지점.
- **죽은 런의 완만한 죽음** — 성벽 낮고 수리비 감당 불가 = 긴 사형 집행. 감쇠형(밀린 판 구제) 미결 우선순위 상향 권고. 회생 불가 판은 겹침 눈덩이가 빨리 끝내주는지 확인.
- **막보스 일찍 부르기** — 찬성 의견. 유일한 "위험을 골라 먹는 판단"이자 잘 풀리는 판의 대기 지루함 해결.
- **게임 속도 옵션** — 난이도 사다리에 게임 속도를 얹으면(낮은 난이도=느린 시간) 실시간 철학 유지하며 진입장벽 완화.
- **빼낸 부대 처리** — 원소 설계가 "갈아탄다"를 전제하므로 환불 규칙이 실질 비용. 전액 소멸이면 갈아타기가 죽고 전액 환불이면 커밋이 죽는다 → 부분 환불 쪽.

### 우선순위 (Claude 의견)

**2(안티-캐치업 스택) · 4(후반 포화) · 1(위기 에이전시)** — 셋 다 "쇼핑이 곧 플레이" 기둥이 특정 상황에서 꺼지는 문제.

## 2. The King is Watching (킹 이즈 와칭) 비교

같은 "실시간·한 화면·성벽 방어 로그라이크"인데 위 헛점들을 반대 방향 장치로 막아둔 게임.

### 구조

- **시선(gaze)이 코어 동사** — 5×5 성 격자, 시선 도형(3칸 시작, 확장) 아래 건물만 생산. 매 순간 "지금 뭘 돌릴 것인가"를 시선 이동으로 선택.
- **건물이 소모품** — 생산량 한도 도달 시 자동 파괴. 자산이 계속 썩어 경제가 포화되지 않음.
- **웨이브 사이클** — 예언 웨이브(다음 전투 3회의 적 구성·보상을 플레이어가 선택) → 전투 3회 → 상점 웨이브.
- **왕의 스펠** — 전투 중 드래그 앤 드롭 광역 스펠 = 긴급 개입 수단.
- **일시정지·배속 있음.** 유닛 전투는 자동, 런 1시간 이내, 메타는 왕·고문관·스킬트리 언락.

### 우리 헛점에 대한 이 게임의 답

| 우리 문제 | 킹 이즈 와칭의 답 |
|---|---|
| 위기 에이전시 없음 | 스펠(직접 개입) + 시선(골드 0이어도 항상 쓸 수 있는 동사) |
| 죽은 시간 | 생산이 시선을 요구 → 유휴 = 손실 |
| 예고가 정보만 | 예언 웨이브 = 예고 + 위험 선택 + 보상 선택 결합 |
| 후반 포화 | 건물 소모품화 → 상점이 끝까지 유효 |
| 실시간 + 읽기 부담 | 일시정지·배속 허용 |

### 이식 가능성

- **호환:** 예고에 선택 얹기(→ 미결 「막보스 일찍 부르기」 근거 보강) · 무자원 동사 확보(→ 미결 「보스 디버프 칸 지정」이 갈림길: 칸 지정이면 재배치가 실시간 회피 동사가 됨) · 배속 선례.
- **비호환:** 자산 소모품화("병력은 잃지 않는다"와 충돌 — 단 원리는 일반 유물=재료 방향이 대신 맡을 수 있음) · 스펠("전투 입력 없음"과 충돌 — 우리는 반대 베팅이며, 성립하려면 위기 중 경제 행동이 개입 수단 역할을 해야).
- 한국 유저 후기 불만점: "자동 전투라 가끔 욕 나오는 상황" — 전투 무입력의 억울함은 장르 공통 과제.

## 3. 유사 장르 탐색

### 장르 지문 6축

① 실시간 연속(라운드 없음) ② 상점·리롤이 코어 플레이 ③ 격자 배치 + 전투 무입력 + 유닛 불사 ④ 성벽 HP 단일 패배 조건 ⑤ 적 소수·순차 등장(단일 대상) ⑥ 로그라이크 런

**결론: 6축을 전부 가진 게임은 없다.**

### 1군 — 실시간 연속 + 전투 중 경제 행동

- **The King is Watching** (2025) — ①④⑥ 강함, ②는 생산 경제로 대체. 시장에서 가장 가까운 단일 게임.
- **랜덤 디펜스 계열** (워크래프트3 유즈맵 계보 — Random Dice: Defense, 럭키 디펜스 등) — 적이 연속으로 밀려오는 동안 골드로 유닛 소환·격자 배치·조합. ①②③ 거의 일치. 차이: 물량 웨이브(⑤ 없음), 합성 중심. 한국 유저에게 "랜덤 디펜스의 실시간 쇼핑 감각 + 로그라이크 런"으로 소개하면 즉시 통할 것.
- **Just King** (2023, 매우 긍정적 90%) — 액션 오토배틀러 로그라이크. 영웅 자동 전투 + 배치 지시 + 킬 보상 쇼핑 = ②③⑥. 차이: 방어전이 아닌 이동형. 상점이 전투 한복판인지는 스토어 설명만으로 미확인.

### 2군 — 구조는 겹치는데 라운드제

- **9 Kings** (2025 스팀 화제작) — 3×3 격자 시작 + 카드(유닛·건물·버프)를 칸에 배치 + 적 군세가 성벽으로 + 로그라이크. ③④⑥ + 카드 문법까지 겹침. 결정적 차이: 턴제 웨이브. **우리 게임의 가장 정확한 정의 = "9 Kings에서 정비 단계를 제거하고 오토배틀러 상점을 이식한 것". 경쟁작 분석 1순위.**
- **오토배틀러 로그라이크 군** (Astronarch, The Last Flame, Despot's Game) — ②③⑥ 일치, 전부 라운드제. "오토배틀러로 표기하지 않는다"는 방침이 시장에서도 유효함을 확인.
- Legion TD 2 — 유닛 배치 오토파이트 + 경제, 라운드제·PvP.

### 3군 — 축 하나만 공유

- **Dome Keeper** — 전투가 흐르는 동안 주의력을 경제에 쓰는 감각(①).
- **Bad North** — 실시간 부대 배치 로그라이트, 무리 실루엣 읽힘(③).
- **Rogue Tower·Emberward·Nordhold** — 로그라이크 TD, 타워 중심(④⑥).
- **Grow Castle 등 성키우기 계열** — 성벽+유닛 슬롯+연속 웨이브, 방치형.

### 시사점

**⑤ "보스급 적만 한 마리씩 걸어오는 단일 대상 방어전"은 어떤 이웃에도 없다.**
- 우리 게임의 진짜 고유 축 → 마케팅 문구의 출처.
- 동시에 검증된 선례가 없는 축 → **프로토타입에서 가장 먼저 재미를 확인해야 할 부분** (1장의 "킬 이벤트 희소·안무 단조" 우려와 같은 자리).
