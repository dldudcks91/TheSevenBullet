## 핵심 질문 (4차)

> **정비↔전투 라운드 구조에서 —**
> **(1) 정비의 「적을 읽고 팩으로 답을 갖추는」 판단이 성립하는가**
> **(2) 전투가 관전이 되지 않는가 — 스킬카드·사기 트레이드오프가 실제로 쓰이는가**
> **(3) 합류 없이 카드 갈아끼우기가 성장으로 느껴지는가**

## 실행

Godot 4로 `TheSevenBullet` 폴더를 연다. `project.godot`의 `run/main_scene`이 이 프로토를 가리킨다. F5.

**화면:** 왼쪽부터 **3×3 격자 → 성벽 → 보스 레인**. 오른쪽 위에 **막보스 상시 표시**(막 시작부터).
정비 중에는 레인 위에 **다음 라운드 적 목록 패널**과 **「전투 시작」 버튼**이 뜬다.
하단 밴드는 왼쪽부터 **팩 4종 진열(유닛·전술·스킬·유물) · 사기 게이지 + 스킬카드 슬롯 5칸 · 유물 5 + 전술 5 보유 슬롯**.

| 조작 | 언제 | |
|---|---|---|
| 팩 클릭 | 정비 | 구매 → **3장 제시 → 1장 택1**, 나머지 소멸. 병사카드는 커서에 붙어 **빈 칸에만** 드래그 배치 |
| 부대를 격자 밖으로 드래그 | 정비 | 빼낸다 (환불 없음) |
| 부대끼리 드래그 | 정비 | 자리 교체 (즉시·무료) |
| 성벽 클릭 / 우클릭 | 정비 | 수리 / 최대 HP 업그레이드 |
| 「전투 시작」 버튼 | 정비 | COMBAT 진입 — 이후 구매·배치·수리 전부 차단 |
| 스킬카드 클릭 | **전투** | **전투 중 유일한 입력.** 사기를 소모해 발동 (대상 자동 — 최근접 적) |
| 호버 / 클릭(핀) / `[Esc]` | 항상 | 상세 카드 열람 — 열람은 입력으로 치지 않는다 |
| `[Space]` | 전투 | 일시정지 + 측정 패널 — **프로토 전용 디버그** (전투 중 일시정지 허용은 기획 미결) |
| `[S]` | | 라운드 안 스폰 모드 전환 (고정 스케줄 ↔ 킬 연동) |
| `[R]` | | 재시작 |

## 4차에서 만든 것

- **정비↔전투 라운드 구조.** Phase = PREP / COMBAT / CLEAR / DEFEAT. 정비는 시간이 통째로
  멈추고(스폰·전진·타격·상태이상 틱·사기) 시간 제한이 없다. 판단은 전부 정비에서
- **라운드 제한시간 + 정산.** 전멸 시 조기 종료. 타임아웃이면 남은 적이 **남은 체력 비례**로
  성벽에 피해를 물리고 사라진다. 패배는 성벽 파괴 하나뿐 — 못 잡는 판도 반드시 정비에 도달한다
- **4막 × 3라운드 = 12라운드.** R1·R2 = 일반+정예 혼합(라운드당 5~6마리 — 확정 수치),
  R3 = **막보스 전용 라운드**(일반 소수 선행). 막이 갈수록 스폰 간격이 좁아진다
- **적 3단.** 일반(접두사 없음·짧고 가볍다·골드 바닥) / 정예(접두사 굴림 — 3차 모델 그대로) /
  막보스(고정 조합 · 막 시작부터 상시 표시). 킬 골드 단별 차등. 스탯 인플레는 막보스에만
- **팩 상점.** 매대·리롤·시간 골드 폐지. "전투가 벌고(킬 골드), 정비가 쓴다."
  등급 게이트 없음 — 문지기는 가격뿐
- **합류제 폐지.** 병사카드 한 장 = 부대 하나, 카드 마릿수가 영구 인원. 빈 칸에만 놓인다.
  마릿수 분포를 체급 상한까지 넓혔다(소형 2~9 / 중형 1~3 / 대형 1) — 갈아끼우기 성장의 낙차
- **전역 사기 + 스킬카드.** 사기 0~100, 30 구간마다 전 부대 데미지 +8%. 라운드마다 0 초기화,
  킬로 충전. 스킬카드 슬롯 5칸(확정 수치), 발동 시 사기 소모 → **구간 아래로 내려가면 버프 상실.**
  임시 풀 5종: 밀쳐내기·빙결탄·정화·파쇄탄·화염탄 (구제 4 + 화력 1 — 「효과의 성격」 미결 양쪽을 태운다)
- **skills.csv 새 effect 3종 글루** — HASTE_STACK(광란) · RANDOM_STACK(취권) ·
  MAGIC_STRIKE_RANDOM(여우불). effect 풀 20종 → 22종

## 「미결」을 프로토가 임의로 고른 자리

기획서에는 적지 않는다. 프로토가 답을 보려고 한쪽을 골라 태운 것뿐이다.

| 미결 항목 | 프로토가 고른 것 |
|---|---|
| 정산 공식 | **남은 체력 비례** (마리당 상한 = wall_dmg × 2.2) — "반쯤 잡은 실패는 덜 아프다"와 맞는 쪽 |
| 막보스의 자리 | **전용 라운드** (막의 R3, 일반 소수 선행) — 막보스도 타임아웃이면 정산되고 사라진다 |
| 팩 개봉 방식 | **3장 제시 → 1장 택1, 나머지 소멸** |
| 유물 획득 | **유물팩** (막보스 보상 안이 아니라 — 획득 문법을 팩 하나로 통일) |
| 사기 충전 소스 | **킬마다** (일반 10 / 정예 26 / 막보스 55 — 재튜닝 미완) |
| 사기 구간 | 가안 그대로 0~100 · 30 구간 · 구간당 전 부대 데미지 +8% |
| 스킬카드 대상 지정 | **자동 — 최근접 적** |
| 스킬카드 교환 시 처분 | 버린 카드 **소멸** |
| 라운드 경계의 디버프·버프 | **리셋** ("시간이 지나면 회복"이 정비를 포함한다고 읽었다) |
| 병사카드 마릿수 분포 | 체급 상한까지 (소형 2~9 / 중형 1~3 / 대형 1) |
| 빗나감 | **0** (3차와 같음) |
| 빼낸 부대 | 환불 없이 사라진다 (3차와 같음) |
| 스폰 스케줄 | `[S]` 토글로 고정·킬 연동 둘 다 태운다 (3차와 같음) |
| 경화 상한 | +14 (3차 발견 — 상한 없으면 한 싸움 안에서 물리 전 편성이 수학적으로 무력화된다) |

## 기획서에 물어봐야 할 것 — **문서에 적지 않았다**

4차에서 새로 생긴 것:

- **사기 가안 수치(0~100 · 30 구간)가 전역 게이지에서 유효한가** — 봇 기준 라운드당 킬 5~6으로는
  상위 구간이 안 열린다. 구간 폭을 줄이거나, 충전 소스를 킬 밖(타격·시간)으로 넓히거나,
  구간을 2개로 줄이는 선택지가 있다
- **막보스가 타임아웃 정산으로 사라지는 것이 의도인가** — 전용 라운드를 골랐더니 "막보스를
  못 잡아도 성벽 피해만 물고 다음 막으로 간다"가 됐다. 유한 런에서 이게 맞는지
- **스킬카드 효과의 성격** — 임시 풀은 구제 4 + 화력 1. 화력 카드(화염탄)가 "딜은 병력이 낸다"와
  어디서 부딪히는지는 플레이로 봐야 한다

3차에서 넘어온 것 (여전히 미답):

- 「로마의 필룸」류 규칙 카드가 감산을 꺼도 되는가 (0.5로 내려 유지 확인까지 한 상태)
- 유물이 동사를 주는 형태 — 3안 중 (2)유니크 전용을 태우는 중
- 「파동」(TC_GOLD_WAVE)의 뜻 — 프로토는 킬마다로 해석. 라운드 개념이 생겨 "라운드 보상" 재표현 후보
- 사선진법의 효과 · 골드 6종/규칙 2종의 실존 전술명 · 규칙 종류의 등급
