> **논의 기록이다 — 기획 확정본이 아니다.** 확정된 것은 [GAME_DESIGN.md](GAME_DESIGN.md)와 데이터 CSV에만 적는다.
> 「구두 확정」과 「제안(미확정)」을 구분해 둔다. 확정되어 기획서·데이터로 옮겨지면 해당 항목은 여기서 지운다.

## 문제 제기

전사·소드마스터·암살자의 차이가 체감되지 않는다. 이 게임은 병력이 피해를 받지 않는 **일방적으로 때리는 구조**라, 수비·위치 축이 없고 근접 물리 셋이 같은 직업처럼 보인다.

## 구두 확정 (기획서 미반영 — 옮길 때 재확인)

- **궁수 = 크리티컬을 보유한 완전 평타 물리딜러.** 물리 딜의 기준선.
- **전사 = 올 물리 피해.**
- **소드마스터·암살자 = 유닛 단위로 물리/마법 혼합.** 어떤 유닛을 마법으로 돌릴지는 사용자가 직접 배정한다.
- **원칙: 직업이 형태(문장)를 주고, 종족이 변주(버프/디버프)를 준다.** 마법사가 완성형 — "캐스팅 후 보스에게 원소 피해".
- **발동 방식은 불변** — 전사·소마=평타 확률, 궁수·암살자=크리티컬, 마법사·사제=캐스팅, 리더=개별.

- 판다 전사 「취권」 — 발동마다 랜덤 강화가 하나 쌓인다 (신규)

## 승인 대기 (제안 상태 — 미확정)

- **직업 형태 문장 3개** — 전사 "때릴수록 달아오른다(자기 강화 스택)" / 소마 "가끔 검술이 나간다(추가 베기, 베기에 성질이 실린다)" / 암살자 "급소가 잡히면 벌리거나 끝을 당긴다". 이 틀 위에서 스킬 확정이 진행됐으나 문장 자체의 기획서 반영은 명시 확정 후에 한다.
- 다크엘프 전사 「짙어지는 그림자」 — 발동마다 관통이 쌓인다 (막힘→통함 뒤집기)
- 인간 검사 「합공」 — 추가 베기가 인접 아군 부대 수만큼 굵어진다
- 다크엘프 소드맨 「연격」의 두 번째 베기에 관통을 실을지 (선택사항)
- 서큐버스 「매혹」 — 크리 순간 보스가 홀려 잠시 되돌아 걷는다 (밀어내기 계열)
- 전사 스택의 수명 = 보스가 죽으면 리셋 (Claude 추천, 답 없음)

## 다른 결정에 걸린 것

- 하이데몬 「업화의 일격」 — 자기 사기를 태워 다음 일격을 굵힌다 ← **사기 결정 대기**
- 리퍼 「영혼 수확」 — 체력 낮을수록 굵게 + 거두면 영구 축적 ← **킬 정의 미결 대기**

## 사기 논의 (진행 중)

기획서에 확정된 뼈대: 모든 부대가 상시 게이지를 갖고, 구간 돌파마다 추가 능력치 (「사기」 절). 미결로 남은 것: 증감 규칙과 구간 보너스 내용.

Claude 추천 3축 — **답 대기**:
1. 구간 보너스 = 공격 주기(속도) 보정 (발동 확률·크리를 직접 만지는 것은 확정 규칙과 충돌하므로 피함)
2. 증감 = 스킬·유물·전술카드·보스만 (자연 증감 없음 — 눈덩이 가속과 숨은 규칙 방지)
3. 수명 = 런 지속 (사기가 부대별 육성 축이 된다)

현재 사기 접점: 야를 「전투 함성」(올림) · 데모네스 「피의 계약」(깎음) · 업화 제안(태움) · 사자후(효과 미정 후보) · 종족 표의 인간(올림)/악마(태움).
